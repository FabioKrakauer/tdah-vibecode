# Jornada de descobertas

Site interativo de psicoeducação, autoconhecimento e autonomia, para ser usado
em sessão pela psicóloga junto com a adolescente.

## Como abrir

Dê dois cliques em `index.html`: abre em qualquer navegador moderno (Chrome,
Edge, Firefox, Safari), no computador, tablet ou celular. Não precisa de
internet, instalação nem servidor.

## Estrutura

| Arquivo | O que tem |
| --- | --- |
| `index.html` | Estrutura da página e ajustes para a psicóloga |
| `css/styles.css` | Identidade visual, layout responsivo, animações e impressão |
| `js/store.js` | Progresso e registros salvos no próprio navegador (`localStorage`) |
| `js/icons.js` | Ícones e ilustrações em SVG (microfone, patins, estrelas, mapa…) |
| `js/ui.js` | Componentes: cartões, campos com salvamento, celebração, lista arrastável |
| `js/mission1.js` | Missão 01 — Entendendo minha mente (holofote, freio dos patins, mitos) |
| `js/mission2.js` | Missão 02 — Da vontade à ação (Organizando o caos + ferramentas de autonomia) |
| `js/mission3.js` | Missão 03 — Entre pensamentos e emoções (história com vários caminhos) |
| `js/final.js` | Capítulo final — Meu caminho daqui pra frente (caderno, carta, mural) |
| `js/pages.js` | Início, mapa da jornada e página de registros |
| `js/app.js` | Navegação entre as páginas |

## Para a psicóloga

- **Ajustes** (ícone no canto superior direito): liberar todas as etapas do
  mapa, ver os registros ou recomeçar a jornada (apaga progresso e registros).
- **Registros**: todas as respostas num só lugar, editáveis, com opção de
  imprimir/salvar em PDF ou baixar em `.txt`.
- A carta do Momento 05 pode ser impressa, salva em PDF ou baixada em `.txt`.
- Cada missão segue Entenda → Experimente → Conecte → Conquista; dá para
  navegar livremente entre as etapas, e nenhum campo é obrigatório.

## Privacidade

Nada é enviado para a internet. Os registros ficam apenas no navegador do
dispositivo em que o site foi aberto. Em uma janela anônima, eles se perdem ao
fechar o navegador. Para levar os registros para outro lugar, use imprimir ou
baixar na página de registros.
